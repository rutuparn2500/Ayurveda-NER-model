# SattvaX - Ayurveda NER System

This Space hosts the web application for SattvaX, an Ayurvedic Named Entity Recognition model.

## Deployment on Hugging Face Spaces

This repository is pre-configured to run as a **Docker** Space on Hugging Face. 
Simply push these files to a new Hugging Face Space (selecting Docker as the SDK), and it will automatically build and run the UI.
